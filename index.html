Grade Calculator

Project 1 • Web Application

This project calculates weighted grades for assignments, quizzes, and exams, so students can see how individual scores affect their final grade.

Technical Stack
  • HTML, CSS, JavaScript
  • Bootstrap 5
  • CodeHS web sandbox
Process & Challenges

I designed the calculator interface to accept different grade weights and validate numeric input. I also ensured the result calculation updated correctly when users changed values.

The main challenge was handling invalid or missing entries without breaking the application. I added input checks and clear error prompts so users always understand what to fix.

Embedded Sensor Project

Project 4 • Embedded Systems

This Arduino-based project gathers sensor readings and reports values over serial, demonstrating a hardware-software integrated solution.

Technical Stack
  • Arduino C++
  • Sensor hardware and serial communication
  • Web reporting interface
Process & Challenges

I designed the sensor polling logic, formatted serial output cleanly, and connected the hardware data stream with a simple web display. I also verified that readings remained stable in real-time.

The main challenge was ensuring reliable communication from the Arduino to the web layer. I validated packet framing and added retries for intermittent serial errors.
