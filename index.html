Grade Calculator

Project 1 • Web Application

This web application models weighted grading schemes so students can forecast their final course grades and understand how assignment scores affect outcomes.

Technical Stack
  • HTML, CSS, JavaScript
  • Bootstrap 5
  • CodeHS web sandbox
Process & Challenges

I designed the user interface to clearly separate grade categories, weights, and score inputs, while keeping the calculation logic modular. I developed validation logic to reject invalid entries and recalculate the total score instantly whenever values changed.

The main challenge was ensuring the formula handled missing or incorrectly formatted values without displaying misleading results. I solved this by adding explicit input checks, user-friendly error messaging, and conditional rendering of the final grade output.

Crypto Tracker

Project 2 • Python Application

This Python application retrieves live cryptocurrency price data and organizes it into a readable report, helping users compare asset values and identify short-term market changes.

Technical Stack
  • Python 3
  • HTTP requests and JSON parsing
  • CodeHS Python runtime
Process & Challenges

I implemented the API fetch flow, parsed nested JSON responses, and formatted numeric values for easy comparison. I focused on creating a robust parser that validated the API response before processing it.

The primary challenge was handling inconsistent or incomplete API data within the sandbox constraints. I added defensive checks, fallback output messages, and clear error handling to keep the application stable during network-style failures.

Multiplayer Dungeon Game

Project 3 • C++ Command-Line Game

This text-based C++ game creates a multiplayer dungeon environment where players explore rooms, fight monsters, and manage items while the program maintains consistent game state.

Technical Stack
  • C++
  • CodeHS C++ sandbox environment
  • Console I/O, structs, arrays, and game loop logic
Process & Challenges

I designed the game architecture with separate systems for player state, enemy encounters, and inventory management, which improved code organization and readability. I also implemented the main game loop and player action handling to support multiple turns and conflict resolution.

The biggest challenge was ensuring that multiple players shared a consistent world state without actions interfering with each other. I used iterative testing and step-by-step debugging to verify that movement, combat, and item usage updated correctly.

Pointers and References C++ Project

Project 4 • C++ Command-Line Application

This C++ project demonstrates pointer and reference usage through a decision-based program that updates variable values across function calls and validates safe memory access.

Technical Stack
  • C++
  • CodeHS C++ sandbox environment
  • Pointer arithmetic, references, and parameter passing
Process & Challenges

I developed examples that compare pointer dereferencing and reference aliasing, including functions that modify values through both approaches. I carefully structured the code to keep pointers initialized and references bound to valid objects.

The key challenge was preventing undefined behavior while demonstrating different memory access patterns. I used focused sandbox tests to confirm each pointer and reference operation produced the expected result.
